이광수 페르소나 — 전체 파이프라인

크게 두 단계. ① 오프라인에서 말투 모델을 굽고, ② 런타임에서 세 에이전트가 협업해 답변을 만든다. 오늘 작업한 대부분은 ①(말투 모델 구축)에 해당한다.

→ 지식 에이전트(RAG) · 검증 기준

핵심 전환

"문체를 검색" → "문체를 모델에 내재화"

기존 버전은 말투를 RAG로 검색·모방했지만, 현재 버전은 1차 사료로 만든 병렬쌍으로 작은 모델을 파인튜닝해 문체를 가중치에 새겨 넣는다. 표면적 모방을 넘어선 심층 페르소나 시뮬레이션.
